# stack-health.service-logs

Static reference for tailing one stack component's logs via docker-compose. Lists the compose service name, when to tail it, and the exact `docker compose logs` invocation for OpenSearch, OSD, OTel Collector, Data Prepper, and Prometheus. Invoke when the user asks how to read a component's logs, why a container is failing, or wants the right `docker compose logs` command.
