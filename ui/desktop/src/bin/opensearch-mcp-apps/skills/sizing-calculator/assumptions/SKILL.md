# sizing-calculator.assumptions

Static reference for sizing inputs (tracesPerDay, avgSpansPerTrace, avgSpanBytes), the assumptions baked into the storage estimate (RED ~1%, service map ~0.5%, 30-day retention), and right-sizing tips (hot/warm tiers, sampling, attribute trimming, replicas, shard size). Invoke when the user asks how the sizing math works, what each input means, or wants tips to bring the estimate down.
