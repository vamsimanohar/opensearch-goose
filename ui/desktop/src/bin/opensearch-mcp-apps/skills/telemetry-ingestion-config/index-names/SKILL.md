# telemetry-ingestion-config.index-names

Static reference table for the canonical observability index patterns: traces (otel-v1-apm-span-*), service map (otel-v2-apm-service-map), logs (logs-otel-v1-*), and the Simple Schema variants. Invoke when the user asks what index pattern to query, where Data Prepper writes data, or wants the standard names.
