# telemetry-ingestion-config.service-map-processor

Static reference for the `otel_apm_service_map` Data Prepper processor — configuration fields (window_duration, group_by_attributes) and the `otel-v2-apm-service-map` output index. Invoke when the user asks how the topology map gets populated, what `window_duration` controls, or wants to scope edges by environment.
