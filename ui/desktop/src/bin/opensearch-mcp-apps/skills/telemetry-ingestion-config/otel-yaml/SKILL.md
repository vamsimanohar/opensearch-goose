# telemetry-ingestion-config.otel-yaml

Static reference for the OpenTelemetry Collector pipeline YAML — receivers (OTLP gRPC/HTTP), processors (memory_limiter / batch / resource), and exporters (Data Prepper, Prometheus remote_write). Invoke when the user asks how to configure the Collector, what processors to use, or wants a working `otel-collector.yaml` starter.
